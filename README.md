Классификация вин: kNN и Softmax-регрессия с нуля, CatBoost

Учебный ML-проект по многоклассовой классификации: самостоятельная реализация двух классических алгоритмов, исследование их поведения и сравнение с градиентным бустингом.
Задача и данные:
Используется датасет Wine из sklearn.datasets.load_wine:
- 178 объектов;
- 13 числовых признаков, описывающих химические характеристики вина;
- 3 класса вин.
Цель - предсказать класс вина по его характеристикам. 
Что реализовано:
- EDA: распределение классов, диаграммы рассеяния и корреляции признаков.
- kNN с нуля: евклидова, манхэттенская и чебышёвская метрики; выбор числа соседей; анализ влияния стандартизации.
- Softmax-регрессия с нуля: вычисление вероятностей, Cross-Entropy, градиентный спуск и L2-регуляризация; исследование скорости обучения и сравнение с sklearn.LogisticRegression.
- CatBoost: обучение многоклассовой модели, подбор глубины и числа итераций, анализ важности признаков.
- Сравнение моделей: Accuracy, Macro F1 и матрицы ошибок на тестовой выборке.
Эксперимент:
Данные разделены со стратификацией на обучающую, валидационную и тестовую выборки (примерно 60% / 20% / 20%). Настройки моделей выбирались на валидации. Для итоговой оценки модели переобучены на объединённых обучающей и валидационной выборках.

Стандартизация для kNN и Softmax-регрессии выполняется по обучающим данным без использования тестовой выборки. CatBoost обучается на исходном масштабе признаков.
Результаты:
kNN (с нуля): Accuracy = 0.9444, Macro F1 = 0.9453
Softmax-регрессия (с нуля): Accuracy = 0.9722, Macro F1 = 0.9710
CatBoost:	Accuracy = 1.0000, Macro F1 = 1.0000

CatBoost верно классифицировал все 36 объектов тестовой выборки. Это результат на данном разбиении, а не гарантия безошибочной работы на новых данных.

Наиболее важными признаками по оценке CatBoost оказались alcohol, flavanoids, proline и color_intensity. Важность признаков отражает вклад в предсказания модели, но не причинно-следственную связь.

Ограничения: датасет небольшой, а качество оценивалось на одном разбиении. Различия в 1–2 верных предсказания не позволяют делать уверенные выводы о превосходстве одного алгоритма в целом.
